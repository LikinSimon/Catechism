How to Maintain This Website Free Forever

100% Zero-Cost Architecture (No Database or Hosting Fees Ever)

This entire portal—including all 28 individual student pages—lives inside a single index.html file so it can run permanently on GitHub Pages or Cloudflare Pages for ₹0.

  1. Initial Setup on GitHub Pages: Create a free account on github.com, create a public repository (e.g., nellikkunnu-catechism), and upload two files: this index.html file and your background photo named Jesus teaching.png. Turn on Settings → Pages → Deploy from main branch.
  2. Customizing Student Pages Anytime: Click Teacher Mode in the top bar (Default PIN: 2026). Open any of the 28 student pages to update their Patron Saint, Attendance %, Term Marks, Prayers Learned, Badges, and Personal Remarks.
  3. Publishing Updates Forever: After editing students, click Export Updated index.html in the Teacher Toolbar. Replace the index.html file in your GitHub repository with the newly downloaded file—every student and parent will immediately see the updated records!
  4. Direct Student Links: Every student has a permanent direct link (e.g., your-site-url/#student-1 for AADIL ALWIN) that you can share directly with parents via WhatsApp.
